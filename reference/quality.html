Engineering Quality

To ensure the reliability of the light simulation, we employ automated testing and documentation-as-code principles.

Automated Testing

We use Vitest for unit testing our core mathematical utilities. This ensures that fundamental operations like vector normalisation and light fall-off calculations remain accurate across changes.

Running Tests

To execute the test suite locally:

npm install
npm test

Current Test Suite

Our tests focus on the src/math_utils.js module, which contains the pure mathematical functions used by the engine.

Module Purpose Status
math_utils.js Vector math and clamping ✅ Passing
engine.js Simulation loop 🔄 In Progress

Continuous Integration (CI)

On every push to the repository, a GitHub Action:

  1. Installs dependencies.
  2. Runs the Vitest suite.
  3. Renders the documentation.
  4. Deploys the bundled site to GitHub Pages.

Link Integrity

We maintain link integrity between the documentation and the source code. The API Reference documents the core solver in src/sim/engine.js.

Contributing Tests

If you add new features to the engine, please include a corresponding test file in the tests/ directory to help maintain the long-term stability of the project.
