## 🌌 The Vision: Escaping the Grid

Traditional computational physics is constrained by **Grid Anisotropy**—the mathematical distortion caused by attempting to map continuous symmetries (like fluid dynamics or quantum wavefunctions) onto rigid, flat $X/Y$ arrays. To fix this, standard engines rely on heavy, error-prone floating-point calculus.

**Lattice Flow** takes a fundamentally different approach. 

By treating physics not as continuous "substances" but as **Information Flow across a Metric**, Lattice Flow utilizes purely discrete mathematics. We replace flat memory arrays with generalized simplicial complexes. By running simple, logical automata on highly symmetric non-Euclidean graphs, complex continuous physical laws emerge naturally, without floating-point approximation. 

## 🔬 Core Capabilities

* **Non-Euclidean Substrates:** Run simulations natively on hyperbolic Cayley graphs, $p$-adic Bruhat-Tits buildings, and aperiodic Penrose tilings. The topology of the memory buffer dictates the physics of the manifold.
* **Quantum Caustics & Catastrophe Theory:** Observe how static geometric obstructions (aperiodic tilings) force dynamic waves into localized singularities and structural instabilities.
* **Topological Data Analysis (TDA):** In-situ computation of topological invariants (Betti numbers) using persistent homology, proving the exact moments of phase transitions and symmetry breaking.
* **Differentiable Automata:** Relaxed logical constraints allow the framework to act as a training ground for Physically Informed Neural Networks (PINNs), learning the attractors of arbitrary phase spaces.
* **WebGPU Compute Buffers:** Bypasses legacy `texture_2d` constraints by utilizing raw structured graph buffers (`NodeState[]` and `EdgeAdjacency[]`) to execute highly parallel, meshless automata natively in the browser.

## 🚀 Getting Started

### Prerequisites
* A WebGPU-compatible browser (Chrome 113+, Edge 113+, or Safari Technology Preview).
* Node.js (v18+)

### Installation

Clone the repository and install the dependencies:

```bash
git clone [https://github.com/your-username/lattice-flow.git](https://github.com/your-username/lattice-flow.git)
cd lattice-flow
npm install
````

### Running the Local Laboratory

Start the React development server:

Bash

```
npm run dev
```

Navigate to `http://localhost:5173` to access the interactive phase-space explorer and topology tools.
