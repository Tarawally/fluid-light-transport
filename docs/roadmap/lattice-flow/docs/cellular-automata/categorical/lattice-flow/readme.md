**A Categorical Automata Framework for Computational Topology**

> "Spacetime is not a container; it is a self-correcting calculation occurring on a frustrated number-theoretic lattice."

**Lattice Flow** is a high-performance simulation engine that replaces continuous floating-point physics with discrete, functorial logic. By running generalized cellular automata on non-Euclidean hyperlattices and Bruhat-Tits buildings, it acts as a universal phase-space propagator—bridging topological data analysis (TDA), catastrophe theory, and quantum geometry.

## 🌌 The Vision: Escaping the Grid

Traditional computational physics is constrained by **Grid Anisotropy**—the mathematical distortion caused by attempting to map continuous symmetries (like fluid dynamics or quantum wavefunctions) onto rigid, flat $X/Y$ arrays. To fix this, standard engines rely on heavy, error-prone floating-point calculus.

**Lattice Flow** takes a fundamentally different approach. By treating physics not as continuous "substances" but as **Information Flow across a Metric**, Lattice Flow utilizes purely discrete mathematics. We replace flat memory arrays with generalized simplicial complexes. By running simple, logical automata on highly symmetric non-Euclidean graphs, complex continuous physical laws emerge naturally, without floating-point approximation.

## 🔬 Core Thesis

### 1. Gravity as Algorithmic Error-Correction (QEC)

In this framework, Gravity is not a fundamental force but the computational overhead of a self-correcting code. If the universe is a hyperbolic tessellation, any conflicting data at the boundaries creates "geometric frustration." Gravity is the active algorithm that warps the local metric to resolve these contradictions, maintaining the global integrity of the network.

### 2. Matter as Topological Frustration

"Particles" are identified as **Matter-Knots**—regions where local logic rules cannot reach a consensus (a Global Section). Due to non-commuting symmetries or geometric obstructions, these persistent errors in the network manifest as stable localized energy densities that we perceive as mass and charge.

## 🛠 Core Capabilities

- **Spectral Embedding (Geometric Truth):** Instead of a fixed grid, the engine uses the first three non-zero eigenvectors $(\psi_1, \psi_2, \psi_3)$ of the **Sheaf Laplacian** ($L_{\mathcal{F}}$) to set the 3D coordinates of the nodes. The simulation "unfolds" its own shape based on internal logical consistency.
    
- **PBR Telemetry (Visual Intuition):** Physically Based Rendering maps "Logical Error" to "Physical Appearance." High-error regions (Matter-Knots) glow with emissive plasma, while consistent logic manifests as mirror-like metallic stability.
    
- **Non-Euclidean Substrates:** Run simulations natively on hyperbolic Cayley graphs, $p$-adic Bruhat-Tits buildings, and aperiodic Penrose tilings. The topology of the memory buffer dictates the physics of the manifold.
    
- **Quantum Caustics & Catastrophe Theory:** Observe how static geometric obstructions force dynamic waves into localized singularities and structural instabilities.
    
- **Topological Data Analysis (TDA):** In-situ computation of topological invariants (Betti numbers) using persistent homology, proving the exact moments of phase transitions and symmetry breaking.
    
- **WebGPU Compute Buffers:** Bypasses legacy `texture_2d` constraints by utilizing raw structured graph buffers (`NodeState[]` and `EdgeAdjacency[]`) to execute highly parallel, meshless automata natively in the browser.

## 🚀 Getting Started

### Prerequisites

- A WebGPU-compatible browser (Chrome 113+, Edge 113+, or Safari Technology Preview).
    
- Node.js (v18+)
    

### Installation

Clone the repository and install the dependencies:

```
git clone [https://github.com/your-username/lattice-flow.git](https://github.com/your-username/lattice-flow.git)
cd lattice-flow
npm install
npm run dev
```
